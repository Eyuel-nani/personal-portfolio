# Eyuel — Personal Portfolio

A clean, responsive personal portfolio built with HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop, tablet and mobile
- About, skills, projects and contact sections
- Mobile navigation menu
- Reduced-motion accessibility support
- Personal profile photo

## Project structure
```text
personal-portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    └── profile.jpg
```

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Deploy with Netlify
Import this GitHub repository in Netlify. Set the publish directory to the repository root (leave the build command blank).
